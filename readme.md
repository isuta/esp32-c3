# ESP32-C3 サーボ制御システム (SG90対応版)

このプロジェクトは、ESP32-C3 Super Miniを使用して、**マイクロサーボ SG90**をJSONファイル（`scenarios.json`）の通りに自動制御するシステムです。

## 接続構成 (SG90)

SG90の配線は以下の通りです：

* **茶色 (GND)** -> ESP32-C3 の **G】ピン**
* **赤色 (VCC)** -> ESP32-C3 の **5V】ピン**
* **橙色 (PWM信号)** -> ESP32-C3 の **GPIO 5】ピン**

## SG90を使用する際の重要な注意点

### 1. 動作範囲（Angle）の調整

SG90は公称180度ですが、実際には「0度」や「180度」付近で物理的なストッパーに当たり、**「ジジジ」と音がして止まらなくなる**ことがあります。

* この状態が続くとサーボが過熱し、**最悪の場合ESP32の故障や火災の原因**となります。
* 最初は `20` ～ `160` 度の範囲でテストし、徐々に広げて安全な範囲を確認してください。

### 2. config.py でのキャリブレーション

SG90の個体差に合わせて、`config.py` の `min_duty` と `max_duty` を微調整してください。

* 0度で唸る場合：`min_duty` を少し大きくする（例：26 → 30）
* 180度で唸る場合：`max_duty` を少し小さくする（例：123 → 120）

### 3. 電力不足について

SG90が急に動く際、一瞬大きな電流（ピーク電流）が必要です。

* 動作中にESP32が勝手に再起動（リセット）する場合、電源（USBケーブルやACアダプタ）の出力不足です。
* 2個以上のSG90を同時に動かす場合は、ESP32経由ではなく、サーボ専用の5V電源を別途用意することを強く推奨します。

## プログラムの構成

* `main.py`: シナリオを繰り返し再生（config.pyの設定に従いループ）
* `servo_controller.py`: SG90をスムーズに動かすための補間処理
* `config.py`: SG90の個体差に合わせたDuty比調整
* `scenarios.json`: 動作パターンの定義
